<details>
<summary><b>🧑‍💻 I'm a developer. Show me the interesting bits.</b></summary>
<br>

- **SensorHub records the loud moments.** It keeps a 5-second pre-roll ring buffer, encodes audio with a [hand-written IMA-ADPCM encoder](https://github.com/SadraShameli/sensorhub/blob/main/include/AdpcmRecorder.h) (4:1), and streams the WAV over HTTPS *while it's still recording*.
- **Firmware as a service manifest.** Every module declares its run mode, stack, priority and start condition, and a [tiny kernel](https://github.com/SadraShameli/sensorhub/blob/main/src/core/Kernel.cpp) boots the lot as FreeRTOS tasks. The core is header-only, so its 30 unit tests run on a PC.
- **Type safety from Postgres to pixels.** [sadra.nl](https://github.com/SadraShameli/sadra.nl) runs on Drizzle, Zod and tRPC, with Vitest and Playwright gating every deploy and Sentry watching production.
- **A backtest has to earn its way into production.** TradingBot's strategies go through walk-forward validation, Monte Carlo and Bayesian optimisation before they touch real money.
- **This README is a build artifact.** The SVGs are generated by [`Scripts/readme`](Scripts/readme) using only the Python standard library, with fonts subset and embedded so they render the same everywhere.
